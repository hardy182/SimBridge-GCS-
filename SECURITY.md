# Security Policy

## Supported Versions
Security updates are actively applied to the latest `main` branch of SimBridge GCS.

## Reporting a Vulnerability
If you discover a security vulnerability within SimBridge GCS:
1. Please report it privately to the maintainers rather than opening a public issue.
2. Provide details of the issue and reproduction steps.
3. Maintainers will review the report and respond with an evaluation and timeline.
